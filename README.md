# 图片尺寸调整器（SAKURA）

> 浏览器扩展（Chrome / Edge，Manifest V3）——把图片拖进侧边栏，批量调整尺寸、转换格式、按规则命名，并自动归档到你指定的文件夹。

操作极简：**拖进来 → 设好尺寸 → 点批量处理**。支持本地文件、整个文件夹、网页图片、剪贴板截图。

> **当前版本 v2.1**，代码在 [`imagetool2.1/`](imagetool2.1)。
> 上一版 v2.0 保留在 [`imagetool2.0/`](imagetool2.0) 仅作归档，不再更新。

## 功能

**收集图片**

- 拖拽到面板任意位置即可添加，支持**一次拖入整个文件夹**（自动递归找图）
- `Ctrl + V` 直接粘贴截图或复制的图片
- 「选择本地文件」多选导入
- 在网页图片上右键 →「用「图片尺寸调整器」处理此图片」
- 未处理的列表会自动保留，**关掉侧边栏再打开不会丢**

**调整与转换**

- 自定义目标尺寸，或存成**尺寸预设**（一键套用，可存多套）
- 三种适配方式：
  - `等比缩放` 长边贴合目标框，不变形（画布贴合实际尺寸，不留白边）
  - `等比裁剪` 填满目标框并居中裁掉多余（做统一缩略图很好用）
  - `拉伸`   强制变成精确宽高，可能变形
- 输出格式：保持原格式 / JPEG / PNG / WebP，JPEG 与 WebP 可调画质
- 「仅转格式」模式：只换格式，不动尺寸

**命名与归档**

- 命名模板可自定义，默认 `组号（组内序号）` → `1（001）.jpg`
- 「每几张一组」决定组号怎么递增
- 可选择**按组建立子文件夹**，输出 `resized_images/1/1（001）.jpg`，多组图片不会混在一起
- 同名文件自动顺延 `(1)(2)`，**绝不覆盖**已有文件

**批量处理**

- 进度条 + 当前第几张，可随时**中止**
- 单张失败不会中断整批，结束后汇总「成功 N 张 / 失败 N 张」
- 处理完发现参数不对？按钮会变成**重新处理全部**，直接再跑一遍

## 安装

本扩展未上架商店，用「开发者模式」加载即可。

1. 获取代码：
   ```bash
   git clone https://github.com/worldconfig/imagetool.git
   ```
   或在仓库页点 **Code → Download ZIP** 后解压
2. 打开 `chrome://extensions`（Edge 用 `edge://extensions`），右上角打开 **开发者模式**
3. 点 **加载已解压的扩展程序**，选择 **`imagetool2.1`** 文件夹（含 `manifest.json` 的那一层）
4. 点击工具栏上的扩展图标，侧边栏就会打开

> 要求 Chrome / Edge **116 以上**。其它 Chromium 内核浏览器如果不支持侧边栏 API，会自动退化成用独立标签页打开，功能照常可用。

## 使用

1. 把图片拖进面板（或粘贴、右键添加）
2. 填目标尺寸后点「应用」，或直接点一个尺寸预设
3. 选好输出格式、命名模板、保存位置
4. 点「批量处理」

### 命名模板变量

| 变量 | 含义 | 示例（每 3 张一组） |
| --- | --- | --- |
| `{组号}` / `{g}` | 第几组 | `2` |
| `{序号}` / `{i}` | 组内第几张，自动补零 | `003` |
| `{全局序号}` / `{n}` | 整个列表第几张，自动补零 | `007` |
| `{原名}` / `{name}` | 原文件名（不含扩展名） | `原图` |

默认模板 `{组号}（{序号}）` 会生成 `1（001）.jpg`。填错变量名会原样保留，界面上有实时预览可以直接看到结果。模板里的路径分隔符会被清理成 `_`，不会意外建出子目录。

### 输出位置

| 模式 | 说明 |
| --- | --- |
| 浏览器下载目录 | 填相对路径（默认 `resized_images`），文件落在下载目录下的这个子目录里。清空则直接存到下载目录 |
| 电脑上的自定义文件夹 | 选一次电脑上任意可写目录（例如 `D:\图片\已处理`），之后直接写入该目录，**不受下载目录限制** |

> 浏览器出于隐私不会把完整路径告诉扩展，所以自定义模式下界面只显示文件夹名。

## 常见问题

**Q：点图标没反应，或者只有一个小弹窗？**
确认 Chrome / Edge 版本 ≥ 116，并在扩展管理页点一次「重新加载」。图标点击会直接开侧边栏，没有弹窗。

**Q：拖网页上的图片进来没反应？**
部分站点有防盗链或跨域限制，扩展拿不到图片数据。请先右键「图片另存为」保存到本地，再拖进来。

**Q：提示「浏览器无法解码该格式」？**
HEIC / TIFF / JXL 等格式浏览器本身解不了，先用系统或在线工具转成 JPG / PNG。

**Q：为什么处理后的动图不动了？**
GIF / 动态 WebP 经画布处理后只会保留静态首帧，这是浏览器画布的固有限制。

**Q：批量下载时 Chrome 提示"是否允许下载多个文件"？**
这是浏览器对连续下载的安全提示，允许即可。改用「电脑上的自定义文件夹」模式不会触发该提示（直接写盘）。

**Q：想让输出落到下载目录以外？**
用「电脑上的自定义文件夹」模式。或者改 Chrome 的默认下载位置；Windows 下也可以用目录联接（无需管理员）：

```cmd
mklink /J "%USERPROFILE%\Downloads\resized_images" "D:\图片\已处理"
```

**Q：图片会被覆盖吗？**
不会。下载目录下由浏览器自动重命名，自定义文件夹下由扩展按 `(1)(2)` 顺延。

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `storage` | 保存你的设置、尺寸预设、命名模板 |
| `downloads` | 把处理结果写入「浏览器下载目录」模式下的子目录 |
| `contextMenus` | 网页图片右键菜单入口 |
| `notifications` | 批量处理完成后的系统通知（可关闭） |
| `sidePanel` | 提供侧边栏界面 |
| `<all_urls>`（主机权限） | 内容脚本注入以支持网页图片拖拽、以及抓取网页图片 |

扩展不收集、不上传任何数据，所有处理都在本地浏览器内完成。
